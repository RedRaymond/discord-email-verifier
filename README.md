# Discord Email Verifier

An open-source, production-ready Discord bot designed for communities, universities, and organizations requiring strict email-based gatekeeping and role distribution.

Built with **Discord.js (v14)**, **Supabase (PostgreSQL)**, and **Nodemailer**.

---

## Features
- **One-to-One Email Binding:** Prevents multiple Discord accounts from registering under the same email.
- **Expiring One-Time Passwords (OTP):** Generates 6-digit codes with a 10-minute validity window.
- **Supabase Persistence:** Stores linked IDs, email addresses, and verification timestamps in a clean relational schema.
- **Automated Role Management:** Automatically updates server member roles upon successful authentication.
- **Ephemeral Responses:** Keeps member emails and codes private during the slash-command interaction.

---

## Database Setup (Supabase)

Create a table named `verified_users` in your Supabase SQL editor:

```sql
create table verified_users (
  id bigint generated by default as identity primary key,
  user_id text not null unique,
  email text not null unique,
  verified_at timestamp with time zone default timezone('utc'::text, now()) not null
);
